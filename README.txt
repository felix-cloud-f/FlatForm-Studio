FlatForm Studio - Android project
1. Install Android Studio (https://developer.android.com/studio) and open this folder.
2. Wait for Gradle sync to finish (needs internet once).
3. Build > Build Bundle(s) / APK(s) > Build APK(s).
4. The file is at app/build/outputs/apk/debug/app-debug.apk - copy it to your phone and install it.
   (Allow "install unknown apps" for your file manager when asked.)
For Play Store release use Build > Generate Signed Bundle / APK.
Requires Android 10 or newer. The app works offline; presets are stored on the device.
